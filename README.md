## 🎮 ProjectGO

Tsim Sha Tsui open-world 3D demo in Three.js — a playable web prototype built from real Hong Kong 3D map data (Open3Dhk). Walk, drive, ride and fly through 460 real buildings.

- Play it: https://kttcat.github.io/ProjectGO/
- Repo: [kttcat/ProjectGO](https://github.com/kttcat/ProjectGO)

## 🛡️ AI workflow & audit

One system in three parts — rules, then tiers, then a paper trail:

- [workflow-skills](https://github.com/kttcat/workflow-skills) — nine learned workflow skills for Muse: verification, approval, and delivery discipline. Each one written after a real mistake.
- [tiered-review](https://github.com/kttcat/tiered-review) — three-tier approval framework for AI agents: approve before high-risk actions, review after low-risk ones, log routine work.
- [sqlite-audit-log](https://github.com/kttcat/sqlite-audit-log) — append-only SQLite audit log with a controlled vocabulary and batch issue tracking.
