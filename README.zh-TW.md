## 🛡️ AI 工作流與稽核

同一套系統，分三部分——規範、分級、留痕：

- [workflow-skills](https://github.com/kttcat/workflow-skills) — 九支搭配 Muse 用的工作流程 skills，講查證、批准、交付的紀律，每一支都是吃過虧之後寫下來的。
- [tiered-review](https://github.com/kttcat/tiered-review) — AI agent 三級審查框架：高風險事前批、低風險事後看、例行只記 log。
- [sqlite-audit-log](https://github.com/kttcat/sqlite-audit-log) — 只增不改的 SQLite 稽核日誌，受控詞彙加批次問題追蹤。
